# HvDropdownButton

The trigger of the UI Kit's dropdowns: a button with a caret that turns while its panel is open. Components use it inside.

## When to use

- Not in projects. A menu of actions: HvDropDownMenu. Choosing a value: HvDropdown or HvSelect. A custom panel under a trigger: HvBaseDropdown.
