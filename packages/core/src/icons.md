# HvIcon

Pentaho UI Kit's own small set of glyphs (carets, close, sort, status), marked private: components use it inside.

## When to use

- Not in projects. Icons come from `@phosphor-icons/react` (search them at phosphoricons.com), sized and colored with HvIconContainer or inherited from the text.
- A status symbol: HvStatusIcon. An icon-only action: HvIconButton.
