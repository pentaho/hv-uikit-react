# HvHeaderBrand

The logo and product name at the start of an HvHeader.

## When to use

- As the first child of HvHeader.

## What the consumer provides

- `logo`: an image with `alt`, or an icon with `aria-label`.

## Spec

- Name in the `label` style; with both `logo` and `name`, a `border` separator `space.sm` tall with `space.xs` margin sits between them.
