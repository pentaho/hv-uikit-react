# HvVerticalNavigationActions

The group of actions pinned to the bottom of an HvVerticalNavigation (settings, help, collapse).

## When to use

- As the last child of HvVerticalNavigation, holding HvVerticalNavigationAction items.

## Spec

- A column pushed to the bottom, gap `space.xs`; hidden when the rail is collapsed without `useIcons`.
