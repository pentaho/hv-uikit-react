# HvVerticalNavigationTreeView

The tree engine under HvVerticalNavigationTree: selection, expansion and keyboard handling for its items.

## When to use

- Use HvVerticalNavigationTree, which builds it from `data`. Compose it by hand only for item content `data` can't express.
