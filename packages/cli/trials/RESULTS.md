# Trial results

One row per run, newest last; `node packages/cli/trials/check.ts … --log` appends one. Checks: `pass`, `fail`, or
`–` when not checked. Built from: the repo commit (`+dirty` with uncommitted changes), a hash of the agent's skills, and
the `@pentaho/*` versions installed. Min, tool calls, tokens and cost come from the transcript; tool calls note whether
the agent ran `npm run check` and how many screenshot commands it ran. Tokens: input (`in`), cache reads (`cr`), cache
writes (`cw`) and output (`out`), summed over API calls. Review: the design-review items met (`3/4 (missed 3)`), then
the verdict.

The first six rows were logged by hand, before this format: Tokens is the agent's final context size, not its usage, and
Review is a verdict without a score. The three `scheduled-jobs` runs also predate the checker (cells from the run
notes).
