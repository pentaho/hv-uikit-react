# Project Status

**UI Kit** is actively maintained by a dedicated team committed to enabling high-quality digital product development. Stay informed about the project’s current status and ongoing development.

## Design System Support

**UI Kit** is now built on the Pentaho Design System, powered by a flexible [theming system](/docs/theming) that allows teams to customize styling to meet their needs.

The library evolved from its original Design System alignment to provide a more design system–agnostic foundation.

To get involved with **UI Kit** development, [open an issue](https://github.com/pentaho/hv-uikit-react/issues/new) or reach out through our channels.

## Browsers Support

**UI Kit** adheres to the [Web Platform Baseline](https://web.dev/baseline) specification, supporting the latest stable versions of all major modern browsers:

| Edge | Firefox | Chrome | Safari (macOS) |
| :--: | :-----: | :----: | :------------: |
|  ✅  |   ✅    |   ✅   |       ✅       |

While most features in **UI Kit** align with the _Widely available_ stage of the Web Platform Baseline,
some may use features from the _Newly available_ stage, following the [_Progressive enhancement_](https://developer.mozilla.org/en-US/docs/Glossary/Progressive_Enhancement) philosophy.

For the best experience, we recommend keeping browsers up to date.
