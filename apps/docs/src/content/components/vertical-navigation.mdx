### Usage

A complete navigation: an icon on every top-level item, nested sections that expand in place, a selected item, and a collapse action pinned to the bottom.

`HvVerticalNavigationTree` renders the structure from a `data` array, and `HvVerticalNavigationActions` holds bottom-aligned actions. Pass `defaultExpanded` an array of ids to decide which sections start open.

Every example on this page uses this same data, so what changes between them is the feature being shown.

> [!NOTE]
>
> The search field in the navigation designs is not part of this component.
> Filter the `data` array in your app and pass the result.

```tsx live
import { useState } from "react";

export default function Demo() {
  const [selected, setSelected] = useState("analytics-reports");
  const [open, setOpen] = useState(true);

  return (
    <div style={{ height: 560 }}>
      <HvVerticalNavigation open={open} useIcons>
        <HvVerticalNavigationTree
          collapsible
          defaultExpanded={["analytics"]}
          aria-label="Product navigation"
          selected={selected}
          onChange={(event, data) => setSelected(data.id)}
          data={navigationData}
        />
        <HvVerticalNavigationActions>
          <HvVerticalNavigationAction
            label={open ? "Collapse menu" : "Expand menu"}
            icon={open ? <Backwards /> : <Forwards />}
            onClick={() => setOpen((prev) => !prev)}
          />
        </HvVerticalNavigationActions>

    </div>
  );
}
```

### Collapsible

To make the navigation collapsible from the top, use `HvVerticalNavigationHeader` with a collapse button. Control the open state via the `open` prop and show the button by passing a handler to `onCollapseButtonClick`.

Enable `useIcons` to display icons when collapsed—defaults to the first letter of the label if no icon is provided.


### Collapsed menu

When the navigation is collapsed (`open={false}`) and `useIcons` is enabled, items are reduced to their icons. Items that have `data` no longer expand in place — they open their children in a flyout beside the rail:

- **Hover** a parent item to preview its children. The flyout closes when the pointer leaves.
- **Click** a parent item to pin the flyout open. Clicking it again, or clicking away, closes it.
- Items without `data` are selected directly and open no flyout.

Items with no `icon` fall back to the first letter of their label.

```tsx live

  const [selected, setSelected] = useState("analytics-reports");
```

### Slider

If you set the `slider` prop to `true`, the navigation will be displayed as a slider instead of a tree. When the user selects an item that contains
children, the content of the navigation will be replaced with the children of the selected item.

You can use this functionality to display the navigation in regular tree view mode and switch to slider mode when the
screen size is lower that a certain threshold.

### Custom content

`HvVerticalNavigation` accepts arbitrary children, so you can place branding, a primary action, or any other content alongside the tree.

```tsx live
import { useState } from "react";

export default function Demo() {
  const [collapsed, setCollapsed] = useState(false);

  return (
    <HvVerticalNavigation open={!collapsed} useIcons>
      <div
        className="flex flex-col gap-md"
        style={{ alignItems: collapsed ? "center" : "stretch" }}
      >
        {collapsed ? (
          <Favorite />
        ) : (
          <div className="flex items-center">
            <Favorite />
            <HvTypography variant="label">Custom App</HvTypography>
          </div>
        )}
        <CollapsibleButton
          collapsed={collapsed}
          variant="primary"
          icon={<Add />}
          label="Create"
        />
      </div>
      <HvVerticalNavigationTree data={data} />
      <HvVerticalNavigationActions>
        <div className="relative">
          {!collapsed && (
            <Backwards className="absolute pointer-events-none top-0 right-0" />
          )}
          <HvVerticalNavigationAction
            label={collapsed ? "Expand menu" : "Collapse menu"}
            icon={collapsed ? <Forwards /> : undefined}
            onClick={() => setCollapsed((prev) => !prev)}
          />
        </div>
      </HvVerticalNavigationActions>
    </HvVerticalNavigation>
  );
}

const CollapsibleButton = ({
  collapsed,
  label,
  icon,
  ...others
}: CollapsibleButtonProps) => {
  const props = collapsed
    ? { "aria-label": String(label), children: icon, icon: true }
    : { startIcon: icon, children: label };

  return <HvButton {...props} {...others} />;
};

const data = [
  { id: "home", label: "Home", icon: <Home /> },
  { id: "marketplace", label: "Data Marketplace", icon: <Storage /> },
  { id: "analytics", label: "Business Analytics", icon: <BarChart /> },
  { id: "settings", label: "Settings", icon: <Settings /> },
];
```
