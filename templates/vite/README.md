# UI Kit App

A standalone app built with React, Vite and HV UI Kit: its routes are in `src/routes.tsx`, its pages in `src/pages`.

```sh
npm install
npm run dev     # the app on a local dev server
npm run check   # format, types and lint, with the UI Kit design rules
npm test        # unit tests
```

For coding agents: `npx --no-install uikit-tools init` points them at the UI Kit's design rules and lookups.
